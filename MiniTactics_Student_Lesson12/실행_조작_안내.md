# 미니 택틱스: 성채 탈환

버전 1.0.0 · Windows 64비트 · Unity 6000.5.3f1

배포 폴더 전체를 유지한 채 `MiniTacticsCampaign12.exe`를 실행하세요. 같은 폴더의 `MiniTacticsCampaign12_Data`, UnityPlayer.dll, 런타임 라이브러리와 지원 폴더가 필요합니다. 기본 창 크기는 1280×720입니다. 필요하면 실행 바로가기 뒤에 `-screen-fullscreen 0 -screen-width 1280 -screen-height 720`을 붙일 수 있습니다.

- 시작 화면의 **새 게임**은 첫 전장을 엽니다. 기존 진행이 있으면 초기화를 확인하며 음소거 설정은 유지합니다.
- **이어하기**는 저장된 전장의 시작으로 이동합니다. 캠페인을 완료했다면 완료 화면을 엽니다. 저장이 없으면 비활성입니다.
- 마우스 왼쪽 버튼으로 아군을 선택하고 이동할 칸을 클릭합니다. 선택된 아군을 다시 클릭하면 제자리에서 행동합니다.
- **공격·스킬**을 누른 뒤 유효한 대상을 클릭합니다. **대기**도 행동을 소비합니다. 검사 강타, 창병 휩쓸기, 궁수 충격 화살, 힐러 대치유를 사용할 수 있습니다.
- 피해·치유·스킬·턴 종료 전에 **이동 취소**로 이동을 되돌릴 수 있습니다. 행동 자체는 되돌릴 수 없습니다.
- **턴 종료** 또는 Enter는 적 차례를 시작합니다. 모든 아군의 행동을 마쳐도 자동으로 적 차례가 시작됩니다.
- **재도전** 또는 R은 현재 전장을 처음부터 다시 시작합니다. 도움말이나 새 게임 확인 창이 열려 있으면 해당 창을 먼저 닫으세요.
- **시작 화면**으로 돌아가기, **도움말**, **음소거** 버튼을 사용할 수 있습니다. 연출 중 전투 입력은 잠시 차단됩니다.
- 적 전멸 시 다음 전장으로, 아군 전멸 시 재도전으로 이어집니다. 세 전장 승리 후 캠페인을 완료합니다.

이어하기는 전장 시작 단위로 저장됩니다. 전투 중 HP·위치·행동은 저장하지 않습니다. 승리 확정 시 다음 전장 또는 완료 상태를 즉시 저장합니다. 전장 전환과 재도전은 네 아군의 HP·행동 상태를 복원합니다. 종료 버튼으로 게임을 마칠 수 있습니다.

이 배포본은 MiniTacticsCourse 제품 저장 위치와 `MiniTactics.Course.Campaign12.v1.*` 키만 사용합니다. 다른 프로젝트의 저장을 삭제하지 않습니다. 실제 플레이 시간 15–25분은 제작 목표이며 아직 측정한 결과가 아닙니다.

Unity 프로젝트의 비교 실습은 Play를 멈춘 뒤 `Assets/Lesson12/Scenes/Lesson12_PoolComparison.unity`를 열고 Play를 누르면 시작합니다. 수업 구현을 완료한 뒤 사용하며, Inspector의 Results/Completed/Output Path와 Console에서 실제 측정 및 저장 위치를 확인하세요. 비교 씬은 최종 캠페인 실행 파일에 포함하지 않습니다.

출처와 사용 조건은 동봉된 `배포_출처_고지.md` 및 `배포고지` 폴더를 참조하세요.

학생용 Unity 시작본은 완성 Lesson11의 저장 키를 이어받습니다. Lesson11에서 이미 설정한 회사·제품 식별자와 네 Campaign12 키를 그대로 사용하며 Lesson12에서 키를 다시 바꾸지 않습니다. 최종 게임을 빌드하기 전에 Lesson12 진행안의 pool/driver 구현과 Inspector 연결을 모두 완료하고 캠페인과 비교 씬을 각각 검증하세요. 신규 pool/driver는 빈 선언이므로 비교 실습도 차시 구현과 Inspector 연결을 마친 뒤 실행합니다.
