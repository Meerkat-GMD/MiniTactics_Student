# 0차시 실습: 상태 이상을 객체로 바꾸기

`Program.cs`는 독, 화상, 재생을 `switch` 문으로 처리합니다. 먼저 실행해서 결과를 확인한 뒤 아래 순서로 바꿉니다.

1. `StatusEffect` 추상 클래스를 만듭니다. 이름을 돌려주는 `Name`과 효과를 적용하는 `Apply(Unit target)`을 선언합니다.
2. 독, 화상, 재생을 `StatusEffect`를 상속한 클래스 세 개로 옮깁니다.
3. `Main`에서 `string[]` 대신 `List<StatusEffect>`를 사용하고, 두 `switch` 메서드를 삭제합니다. 실행 결과가 처음과 같아야 합니다.
4. 출혈을 추가합니다. 출혈은 턴마다 피해가 1, 2, 3으로 늘어납니다. 이미 만든 클래스는 고치지 않습니다.

`Unit.cs`는 수정하지 않습니다.
