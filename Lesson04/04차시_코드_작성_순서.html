작성 단계

30–42분Step 1

InputState 계약 확인

Assets/Lesson04/Scripts/InputState.cs

Enter, Exit는 선택적으로 재정의하는 virtual 메서드로 두고, 클릭과 Undo는 모든 상태가 구현해야 하는 abstract 메서드로 둔다.

public abstract void HandleBoardClick(
    Unit clickedUnit, Vector2Int cell);
public abstract void HandleUndo();
완료 신호: IdleState와 UnitSelectedState가 같은 네 메서드를 가진다.
42–60분Step 2

InputStateMachine 전환 완성

InputStateMachine.cs

  1. next가 null이면 예외
  2. Current와 같은 인스턴스면 return
  3. Current?.Exit()
  4. Current = next
  5. Current.Enter()
완료 신호: 전환 순서를 Exit → 교체 → Enter로 소리 내어 설명한다.
막히면: ReferenceEquals(Current, next)를 사용한다.
60–68분Step 3

입력을 Current에 전달

InputStateMachine.cs

Current?.HandleBoardClick(clickedUnit, cell);
Current?.HandleUndo();

여기서는 유닛 선택 여부나 이동 가능 여부를 판단하지 않는다.

완료 신호: State Machine에는 게임 규칙 if문이 없다.
68–80분Step 4

IdleState의 선택 시작

IdleState.cs

machine과 controller를 필드에 저장한다. 클릭한 유닛이 있고 CanMove라면 새 UnitSelectedState로 전환한다. Undo는 controller.UndoLast()에 맡긴다.

완료 신호: 빈 셀 클릭은 아무 동작도 하지 않는다.
80–98분Step 5

UnitSelectedState의 생명주기

UnitSelectedState.cs

machine, controller, unit을 필드에 저장한다. Enter에서 ShowSelection(unit), Exit에서 ClearSelection()을 호출한다.

public override void Enter()
    => _controller.ShowSelection(_unit);
public override void Exit()
    => _controller.ClearSelection();
완료 신호: 어떤 경로로 선택 상태를 떠나도 오버레이가 사라진다.
98–112분Step 6

선택 교체와 이동 후 복귀

UnitSelectedState.cs

다른 이동 유닛을 클릭하면 새 선택 상태로 전환하고 return한다. 그 외에는 ExecuteMove(unit, cell)를 호출한 뒤 IdleState로 전환한다.

완료 신호: 세 유닛을 클릭할 때 선택 범위가 즉시 바뀐다.
선택이 풀리면: 다른 유닛 분기 뒤 return이 있는지 본다.
112–135분Step 7

BattleController를 Context로 연결

BattleController.cs

InputStateMachine 속성을 만들고 처음 IdleState를 넣는다. Update의 선택/이동 분기를 한 줄의 HandleBoardClick 호출로 바꾼다. ShowSelection, ClearSelection, ExecuteMove, UndoLast를 작은 메서드로 분리한다.

StateMachine.HandleBoardClick(
    clickedUnit, _board.WorldToCell(worldPosition));
완료 신호: Update가 현재 선택 여부를 직접 검사하지 않는다.
135–150분Step 8

Undo를 현재 상태로 전달

BattleController.cs · 두 State 파일

OnUndoClicked는 StateMachine.HandleUndo()만 호출한다. 선택 상태의 Undo는 되돌린 다음 ShowSelection(unit)을 호출해 범위를 새로 그린다.

완료 신호: 이동 → 선택 → Undo 뒤에도 선택 범위가 현재 위치와 맞는다.
150–168분Step 9

3유닛 플레이 미션

  1. (2,2), (5,4), (8,6)의 유닛을 차례로 선택
  2. 첫 유닛을 유효 셀로 이동
  3. 다른 유닛으로 즉시 선택 전환
  4. 점유 셀과 강 셀 이동 거부 확인
  5. Undo 두 번 확인
완료 신호: 중복 유닛과 Console 오류가 없다.
168–180분Step 10

전환표로 설명하기

Idle과 UnitSelected 각각에서 유닛 클릭, 빈 셀 클릭, Undo가 무엇을 하는지 표로 적는다. State와 Context가 각각 결정과 실행 중 무엇을 맡는지 설명한다.

완료 신호: “모든 전환은 Exit → 교체 → Enter”를 코드와 함께 설명한다.

최종 제출 전 확인

  • State 파일의 빈 메서드를 모두 채웠다.
  • 세 유닛 선택 전환과 이동이 동작한다.
  • Undo 뒤 위치와 오버레이가 맞다.
  • Play Mode 재시작에도 유닛이 늘어나지 않는다.
  • Console에 오류가 없다.
