30–45분Step 1

TerrainType의 불변 데이터 완성

Assets/Lesson03/Scripts/TerrainType.cs

생성자가 이름·이동 비용·통행 가능 여부를 받아 getter-only 속성에 저장하게 한다. 빈 이름과 0 이하 비용은 거부한다.

public TerrainType(string name, int movementCost, bool isWalkable)
{
    if (string.IsNullOrWhiteSpace(name))
        throw new ArgumentException("Terrain needs a name.", nameof(name));
    if (movementCost <= 0)
        throw new ArgumentOutOfRangeException(nameof(movementCost));

    Name = name;
    MovementCost = movementCost;
    IsWalkable = isWalkable;
}
완료 신호: 저장 후 컴파일 오류가 없고 기존 게임이 실행된다.
막히면: 파일 위에 using System;이 있는지, 속성 이름의 대소문자가 같은지 본다.

90–120분Step 5

누적 비용이 가장 작은 셀부터 탐색

MovementRange.cs · MovementRange.Calculate

  1. 시작이 Board 밖이거나 강이면 빈 결과를 반환한다.
  2. 시작 비용 0과 frontier를 만든다.
  3. frontier에서 현재 비용이 가장 낮은 셀을 고른다.
  4. 상하좌우 이웃을 검사한다.
int candidateCost = costs[current] + terrain.MovementCost;

if (candidateCost > budget)
    continue;

if (costs.TryGetValue(next, out int knownCost)
    && knownCost <= candidateCost)
    continue;

costs[next] = candidateCost;
previous[next] = current;
frontier.Add(next);
완료 신호: 코드가 컴파일되고 무한 반복 없이 Play Mode가 시작된다.
무한 반복이면: current를 frontier에서 제거하는 줄과, 기존 비용보다 싸지 않으면 건너뛰는 조건을 확인한다.

150–165분Step 9

최종 플레이 목표

  1. 평지 방향과 숲 방향의 범위를 비교한다.
  2. 숲 한 칸이 비용 2를 쓰는지 확인한다.
  3. 강 셀 이동이 거부되는지 확인한다.
  4. 유효한 셀로 세 번 이동한다.
  5. Undo 두 번으로 최근 두 이동을 역순 복원한다.
완료 신호: 모든 동작 뒤에도 Console에 오류가 없다.

제출 전 확인

  • 지형 객체는 네 개만 생성된다.
  • 숲 비용 2, 산 비용 3이다.
  • 강은 통행 불가다.
  • 예산 밖 셀은 표시되지 않는다.
  • 더 싼 경로가 비용을 갱신한다.
  • 경로가 시작→목표 순서다.
  • 점유 셀에 이동하지 않는다.
  • 제자리 이동을 기록하지 않는다.
  • Command/Undo가 유지된다.
  • Console 오류가 없다.
